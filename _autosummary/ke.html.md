# ke

`ke` – reserved for a future knowledge-*extraction* package.

This repository used to hold a first draft of knowledge-*evaluation* tooling.
That work continued under the name [ek](https://github.com/thorwhalen/ek)
(read as “evaluation of knowledge”) and has since grown well past what lived
here – see `ek`’s own documentation for evaluating information-extraction
outputs (OCR, agents, and more).

`ke` itself is kept empty and reserved for knowledge *extraction* (the
inverse problem: producing structured knowledge from raw sources), which is
not yet implemented. See
[issue #12](https://github.com/thorwhalen/ke/issues/12) for the history of
this reset and [AGENTS.md](../AGENTS.md) for what a future build here
should look like.
